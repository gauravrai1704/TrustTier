# TrustTier final paper (Overleaf project)

Upload this zip to Overleaf (New Project -> Upload Project). Compiler: pdfLaTeX; BibTeX runs automatically.

- main.tex                     the paper (acmart, sigconf, two columns)
- references.bib               48 references; 36 checked against their sources; 12 added later from memory need checking against their publisher, arXiv/ePrint or official documentation (BlockRaFT, added last, still needs checking against the arXiv page)
- figures/band_sensitivity.tex tier-band figure and threshold table, generated by off-chain/evaluation/band_sensitivity.py
- figures/ext/                 every TikZ/pgfplots figure pre-rendered to PDF, so compiles stay inside Overleaf's free-plan time limit
                               (to change a figure, edit it in main.tex, delete its figures/ext/main-figureN.* files and recompile)
- preview.pdf                  the compiled paper

Every number in the paper comes from scripts in the project repository (see Appendix A of the paper).
